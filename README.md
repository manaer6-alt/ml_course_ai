# mlcourse.ai Learning Track

A structured record of my work through the mlcourse.ai curriculum: exploratory analysis, supervised learning, feature engineering, validation, and practical model evaluation.

## Purpose

This repository complements the applied portfolio projects. It documents the foundations behind them and shows how I turn course material into reproducible notebooks and concise technical conclusions.

## Topics covered

- Exploratory data analysis and visualization.
- Decision trees, ensembles, and linear models.
- Cross-validation and model selection.
- Feature engineering for tabular data.
- Classification and regression metrics.
- Avoiding leakage and separating validation from final evaluation.

## Repository guide

- Topic folders contain notebooks, exercises, and notes.
- Reports summarize completed work and key takeaways.
- Environment files record the dependencies used for the exercises.

## Current direction

I am applying these foundations to credit-risk scoring, financial analytics, and interpretable tabular machine learning. The strongest end-to-end examples are highlighted on my GitHub profile.

## Stack

Python · pandas · NumPy · scikit-learn · Jupyter · Matplotlib · Seaborn
