# mlcourse.ai learning track

Self-paced прохождение открытого курса mlcourse.ai.

## Goal

Цель системно пройти курс, закрепить classic ML, pandas, EDA, validation, feature engineering, model comparison, gradient boosting и перенести знания в собственные tabular ML projects.

## Course structure

- 00 Intro  prerequisites
- 01 Pandas
- 02 Visual Data Analysis
- 03 Decision Trees, KNN, Cross-validation
- 04 Linear Models
- 05 Bagging and Random Forest
- 06 Feature Engineering
- 07 Unsupervised Learning
- 08 SGD  Vowpal Wabbit
- 09 Time Series
- 10 Gradient Boosting

## Progress

Progress is tracked in `progress.md`.

## Reports

Lesson reports are stored in `reports`.

## Main rules

- No passive watching.
- Every lesson must produce notes andor code.
- Every assignment gets an attempt before checking solution.
- Validation and leakage are checked explicitly.
- Test set is not used for tuning.
- Every major topic ends with a report.
